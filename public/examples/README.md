# Example resumes

These example LaTeX resumes are included so people can evaluate Tailor without uploading a personal document.

- `jake-ryan.tex` is the Jake Gutierrez resume template, based on the `sb2nov/resume` project and distributed under the MIT License.
- `jane-doe.tex` is the Rezume developer template by Nanu Panchamurthy, based on the `sb2nov/resume` project and distributed under the MIT License.

The original author and license comments are preserved at the top of each source file.
